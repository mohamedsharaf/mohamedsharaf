في 2014 قارن مطوّر ووردبريس نيكولا موليه (Nicolas Mollet) بين الإضافات التي كان الناس يستخدمونها لإنشاء أنواع مقالات مخصصة من دون كتابة كود: Easy Post Types وCustom Post Type UI وWP Post Type UI وCMS Press وGD Custom Posts And Taxonomies Tools. وكان اختياره الشخصي Custom Post Type UI مع إضافة منفصلة للحقول المخصصة.

بعد عقد كامل، ما زالت هذه التوليفة هي الإجابة الشائعة: Custom Post Type UI (أو بضعة أسطر من register_post_type() في القالب أو في إضافة صغيرة) للأنواع نفسها، وAdvanced Custom Fields أو ما يشبهها لحقولها. وتسجيل الأنواع في الكود هو الخيار الأكثر قابلية للنقل، لأنها لا تختفي إذا حُذفت إضافة.
