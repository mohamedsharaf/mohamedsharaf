In 2014, WordPress developer Nicolas Mollet compared the plugins people used to create custom post types without writing code: Easy Post Types, Custom Post Type UI, WP Post Type UI, CMS Press, and GD Custom Posts And Taxonomies Tools. His personal choice was Custom Post Type UI, paired with a separate plugin for custom fields.

A decade later, that pairing is still the common answer: Custom Post Type UI (or a few lines of register_post_type() in your theme or a small plugin) for the types themselves, and Advanced Custom Fields or similar for their fields. Registering post types in code is the most portable option, because they don’t disappear if a plugin is removed.
