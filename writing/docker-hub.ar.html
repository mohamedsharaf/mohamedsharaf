قالت Docker يوم الجمعة إن شخصًا وصل إلى قاعدة بيانات في Docker Hub فيها بيانات نحو 190 ألف حساب: أسماء المستخدمين، وكلمات المرور المجزّأة، ورموز GitHub وBitbucket المستخدمة في البناء الآلي. وألغت Docker هذه الرموز.

هذه الرموز تستطيع قراءة كودك المصدري، وأحيانًا الكتابة فيه.

ماذا تفعل:

  1. غيّر كلمة مرور Docker Hub، وفي أي مكان آخر استخدمتها فيه.
  2. راجع سجلات الأمان في GitHub وBitbucket بحثًا عن وصول غير متوقع أو مفاتيح نشر جديدة.
  3. أعد ربط البناء الآلي برموز جديدة، بأقل صلاحيات تكفي.
  4. راجع الصور التي تسحبها من Docker Hub، وثبّتها ببصمتها (digest).

كل خدمة مربوطة بمستودعات كودك جزء من أمانك. احتفظ بقائمة، واحذف ما لم تعد تستخدمه.
