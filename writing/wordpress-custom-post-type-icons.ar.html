في 2011، كان إعطاء نوع المقالات المخصص (Custom Post Type) أيقونة خاصة في القائمة يعني حقن CSS مع صورة من مجموعة أيقونات Fugue. منذ ووردبريس 3.8 أصبح ذلك معاملًا واحدًا عند تسجيل النوع:

register_post_type( 'project', array(
    'label'     => 'Projects',
    'public'    => true,
    'menu_icon' => 'dashicons-portfolio',
) );

يقبل menu_icon أي اسم من مجموعة Dashicons المدمجة، أو رابط صورة خاصة بك، أو SVG مُرمَّزًا كنص data:image/svg+xml;base64,…. من دون أي CSS إضافي.
