Friends who managed several cPanel servers kept asking the same thing: how do you build Apache and PHP once and reuse that exact setup everywhere? EasyApache saves your choices as a profile file, so you can copy that file to the other servers.

On the old EasyApache 3, custom profiles live in:

/var/cpanel/easy/apache/profile/custom/

Copy your profile from the source server to the same folder on the target server:

scp /var/cpanel/easy/apache/profile/custom/myprofile.yaml root@target:/var/cpanel/easy/apache/profile/custom/

Then, on the target server, start EasyApache, choose that profile and build.

Today: EasyApache 3 has been retired. EasyApache 4 keeps profiles in /etc/cpanel/ea4/profiles/custom/, and you can export one in WHM and apply it on another server with /usr/local/bin/ea_install_profile. The idea is the same: build once, copy the profile.
