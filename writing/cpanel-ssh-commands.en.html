A short list of cPanel commands I used again and again from SSH, as root:

Install cPanel on a fresh server

cd /home && curl -o latest -L https://securedownloads.cpanel.net/latest && sh latest

Back up a single account

/scripts/pkgacct USERNAME

This creates a cpmove-USERNAME.tar.gz file you can move to another server and restore.

Run the scheduled backups now

/usr/local/cpanel/bin/backup --force

On older servers the same job was /scripts/cpbackup --force. Whatever the command, a backup only counts once you have restored it somewhere and checked it.
