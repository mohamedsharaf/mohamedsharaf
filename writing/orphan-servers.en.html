In almost every network review I find at least one: a server that still answers but has no owner. An old intranet, a test copy of the website, a reporting tool from a project that ended, a virtual machine someone cloned “for a minute” in 2022.

Nobody patches it because nobody thinks it’s theirs. Attackers love it for exactly that reason.

  1. Compare what’s actually running, from your hypervisor, cloud console and network scans, with your asset list.
  2. For every machine without an owner, send a short notice: “This will be shut down on the 15th unless someone claims it.”
  3. Shut down, don’t delete. Wait a month for anyone who screams.
  4. Then take a final backup and delete it.
  5. From now on, every new server gets an owner and an end date when it’s created.
