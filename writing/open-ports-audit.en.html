Attackers don’t start with your website. They scan every address you own and look for anything listening: an old remote desktop, a database, a printer’s web page, a test server from last year.

You can see the same thing they see, for free.

  1. List your public IP addresses and domains. Your ISP, cloud console and DNS records will give you most of them.
  2. Look them up on Shodan or Censys, or run nmap from outside your network.
  3. For each open port, answer: what is it, who owns it, does it need to be public?
  4. Close what isn’t needed. Put admin interfaces behind a VPN or an access proxy.
  5. Repeat monthly, or set up alerts for new open ports.

The first scan is always surprising. Usually the surprise is something someone set up “just for a week”.
