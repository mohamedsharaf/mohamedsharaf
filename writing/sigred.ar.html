تحديثات Windows يوم الثلاثاء أصلحت CVE-2020-1350، الملقبة SIGRed: ثغرة في Windows DNS Server موجودة منذ 17 عامًا. رد DNS خبيث قد يسمح للمهاجم بتشغيل كود بصلاحية SYSTEM. وتصنّفها Microsoft قابلة للانتشار الذاتي وبتقييم 10 من 10.

في معظم الشركات، وحدات التحكم بالنطاق هي نفسها خوادم DNS. وهذا يجعلها في أعلى درجات الخطورة.

  1. ثبّت تحديث يوليو على كل خادم Windows يشغّل دور DNS، بدءًا بوحدات التحكم بالنطاق.
  2. إن لم تستطع التحديث اليوم، فطبّق تعديل السجل من Microsoft الذي يحدّ حجم حزم DNS عبر TCP، ثم أعد تشغيل خدمة DNS.
  3. تأكد أن خوادم DNS الداخلية لا يمكن الوصول إليها من الإنترنت.

أجهزة Windows العادية غير متأثرة، بل الخوادم التي تشغّل DNS Server فقط. القائمة قصيرة، فلا تدعها تنتظر.
