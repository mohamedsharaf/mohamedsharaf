جعل Zend Framework 1 خدمة REST الأساسية شبه مجانية: اكتب كلاس PHP عاديًا، ويعرض Zend_Rest_Server دواله العامة عبر HTTP. داخل أحد الـ Controllers:

$server = new Zend_Rest_Server();
$server->setClass('ProductService');
$server->handle();

طلب مثل /api?method=findProduct&id=42 يستدعي ProductService::findProduct(42) ويعيد النتيجة بصيغة XML.

اليوم: توقف Zend Framework 1 منذ زمن (ويستمر المشروع باسم Laminas)، ومعظم واجهات API اليوم تتحدث JSON مع طرق HTTP ورموز حالة صحيحة (انظر طرق طلبات HTTP بكلام بسيط). ويبقى الدرس صالحًا: ضع منطق العمل في كلاسات عادية، ودع طبقة رقيقة تتولى جزء الويب.
