To delete a folder with all its files and subfolders on a Linux server:

rm -rf /path/to/folder
  • -r removes the folder recursively, with everything inside it.
  • -f forces it, without asking for confirmation.

That last part is exactly why it needs respect. There is no recycle bin and no “are you sure?”. Before pressing Enter, run ls /path/to/folder to see what you are about to delete, avoid wildcards you have not checked, and never run it with a path built from a variable that might be empty.
