الحقول المخصصة (Custom Fields) تسمح لك بإرفاق معلومات إضافية بالمقال: سعر منتج، تقييم كتاب، سطر عن «المزاج». كل حقل عبارة عن زوج بسيط: مفتاح وقيمة.

١. أضف حقلًا

في محرر المقال، افتح لوحة Custom Fields (في محرر المكوّنات فعّلها من Preferences ← Panels). أضف مفتاحًا مثل rating وقيمة مثل 4.5.

٢. اعرضه في قالبك

داخل حلقة القالب (مثل single.php):

<?php $rating = get_post_meta( get_the_ID(), 'rating', true ); ?>
<?php if ( $rating ) : ?>
  <p class="rating">Rating: <?php echo esc_html( $rating ); ?></p>
<?php endif; ?>

المعامل الثالث true يعيد قيمة واحدة بدل مصفوفة. واحرص دائمًا على تمرير المخرجات عبر esc_html(): الحقول المخصصة محتوى، والمحتوى قد يحتوي أي شيء.
