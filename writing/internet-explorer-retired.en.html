Last Wednesday Microsoft retired Internet Explorer 11 on most versions of Windows 10. Opening it now sends you to Edge. After 27 years, that’s the end of a browser most of us were happy to forget.

Except in companies. Many still run an old intranet, an ERP screen or a government portal that only works in IE. For those, Edge has “IE mode”, which keeps the old engine alive inside Edge.

What I’d do:

  • List the sites that need IE mode. Your Edge policy’s site list is a good start.
  • Keep that list short and controlled through policy, not users clicking “reload in IE mode” everywhere.
  • Ask each vendor for a date when their app will work in a modern browser.
  • Keep Windows patched. The old engine still gets security fixes, and attackers still target it.

IE mode is a bridge, not a home. Every app that leaves it is one less old engine to worry about.
