Few things are more annoying than coming back to your desk and finding that Windows restarted itself for updates, with your work still open. On Windows 8 (Pro and above), and still on Windows 10 and 11 Pro, a Group Policy setting prevents that:

  1. Press Win+R, type gpedit.msc and press Enter.
  2. Go to Computer Configuration → Administrative Templates → Windows Components → Windows Update (on Windows 11: … → Windows Update → Manage end user experience).
  3. Open “No auto-restart with logged on users for scheduled automatic updates installations”, set it to Enabled, and click OK.

Updates still install; Windows just waits until you restart it yourself. Don’t forget to actually restart, because security updates only protect you once they are applied. On newer Windows, “Active hours” in Settings helps too.
