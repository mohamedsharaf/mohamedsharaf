الـ View استعلام محفوظ تستخدمه كأنه جدول، ومفيد عندما يتكرر الفلتر نفسه أو الربط نفسه في كل مكان:

CREATE VIEW active_customers AS
SELECT id, name, email
FROM customers
WHERE status = 'active';

الآن يعمل SELECT * FROM active_customers كأي جدول، ويبقى المنطق في مكان واحد. ولتعديله لاحقًا استخدم CREATE OR REPLACE VIEW.

والـ Views أيضًا أداة بسيطة للتحكم في الصلاحيات: امنح مستخدم التقارير صلاحية على الـ View وحده، فلن يرى أبدًا الأعمدة التي استبعدتها.
