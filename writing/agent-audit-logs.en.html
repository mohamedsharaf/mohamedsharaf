AI agents in companies have moved from answering questions to doing things: updating tickets, sending emails, changing CRM records, running scripts. When something goes wrong, the first question is “what exactly did it do, and why?” Often nobody can answer.

Before an agent gets write access anywhere, make sure you can answer that:

  • Every action is logged with the agent’s own identity, not the human user’s, plus who asked for it.
  • Keep the instruction or task that triggered each action, and the tool calls it made.
  • Send those logs where your other security logs go, and keep them as long.
  • Alert on unusual activity: bulk changes, actions outside working hours, new destinations for emails or files.
  • Make it easy to pause an agent instantly.

If you can’t explain an agent’s actions to an auditor or a customer, it shouldn’t be taking them.
