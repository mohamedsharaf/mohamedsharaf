On 14 October 2025, Windows 10 stops getting free security updates. The PCs keep working. They just stop getting fixes, and every hole found after that stays open.

Three options:

  1. Upgrade to Windows 11 if the PC supports it (it needs TPM 2.0 and a recent enough CPU). Check in Settings, Windows Update. It’s free.
  2. Pay for Extended Security Updates to buy time. Microsoft offers them for a limited period. Use it as a bridge, not a plan.
  3. Replace the machine. Old hardware that can’t run Windows 11 is often near the end anyway.

Do this week:

  • List every Windows 10 machine, including the one running the reception camera or the old accounting app.
  • Upgrade the ones that can. Plan the rest.
  • Anything that must stay on Windows 10 for now: no email, no web browsing, and keep it off the main network.
