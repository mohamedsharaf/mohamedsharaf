بعد شهرين من حزم LiteLLM الملغومة، يواجه الوكيل مشكلة مختلفة. ثغرة حقن SQL حرجة في إصدارات وكيل LiteLLM من 1.81.16 إلى 1.83.6 تتيح لمهاجم دون تسجيل دخول قراءة قاعدة بيانات الوكيل، وربما تعديلها. أضافتها CISA إلى قائمة الثغرات المستغلة الأسبوع الماضي، ورصد الباحثون محاولات استغلال بعد نحو يوم ونصف من النشرة.

قاعدة البيانات هذه تحمل عادة مفاتيح API الافتراضية، وميزانيات الفرق، وسجلات الاستخدام، وإعدادات كل مزوّد نماذج.

  • حدّث الوكيل إلى إصدار مُصلح الآن.
  • لا تكشف واجهة الإدارة وواجهة API الخاصة بالوكيل على الإنترنت. ضعهما خلف VPN أو بوابة وصول.
  • إن كان مكشوفًا بإصدار مصاب، فغيّر المفتاح الرئيسي، والمفاتيح الافتراضية، ومفاتيح المزوّدين المحفوظة فيه.
  • راجع لوحات المزوّدين بحثًا عن ارتفاعات في الاستخدام لا تفسير لها.

بنية الذكاء الاصطناعي بنية عادية: تطبيقات ويب وقواعد بيانات وأسرار. تحتاج التحديث نفسه.
