في 2010 وضعت مقارنة شائعة منصات الويب الثلاث الكبرى جنبًا إلى جنب:

  • PHP (‏LAMP): بلا تكاليف ترخيص، واستضافة رخيصة في كل مكان، ومجتمع ضخم. وكان القلق المعتاد جودة الكود حين تتداوله أيدٍ كثيرة.
  • ASP.NET: أدوات ممتازة، لكنه مرتبط بـ Windows Server وغالبًا SQL Server، فتتراكم تكاليف التراخيص.
  • Java EE (‏J2EE): مجاني من حيث المبدأ وقوي في المؤسسات الكبيرة، لكنه أثقل في التشغيل وأبطأ في التطوير.

ما الذي تغيّر

اختفت حجة التكلفة في معظمها: أصبح .NET مفتوح المصدر ويعمل على لينكس، وتحول Java EE إلى Jakarta EE، وأصبح PHP الحديث (8.x) سريعًا وأكثر صرامة بكثير مما كان في 2010. واليوم السؤال الأفضل ليس أي منصة هي الأفضل، بل أيها يعرفها فريقك جيدًا، وأيها يناسب استضافتك، وأيها تستطيع أن تبقيه آمنًا ومحدّثًا لسنوات.
