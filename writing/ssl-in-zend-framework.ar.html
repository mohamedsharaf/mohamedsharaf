في 2012 كان HTTPS مكلفًا بما يكفي لأن تستخدمه مواقع كثيرة حيث يهم فقط: الدخول وسلة الشراء والدفع. وفي Zend Framework 1 كنا نفعل ذلك بإضافة (Plugin) للـ Front Controller تقرأ قائمة الصفحات الآمنة من ملف إعدادات:

; ssl.ini
ssl.modules.default.require_ssl = false
ssl.modules.default.controllers.account.require_ssl = true
ssl.modules.default.controllers.checkout.require_ssl = true

كانت الإضافة تفحص كل طلب مقابل هذه القائمة في preDispatch()، وتعيد التوجيه إلى عنوان https:// عند الحاجة (وتعود إلى http:// في غيرها).

اليوم: لا تفعل ذلك. الشهادات مجانية، وHTTPS لا يكلف شيئًا تقريبًا، والخلط بين HTTP وHTTPS يسرّب كوكيز الجلسة. قدّم الموقع كاملًا عبر HTTPS، وحوّل كل طلبات HTTP إليه، وأرسل ترويسة HSTS حتى لا تحاول المتصفحات HTTP العادي مرة أخرى.
