Sometimes a controller action shouldn’t render a template at all, for example when it returns a file, a redirect or raw JSON. In Zend Framework 2 you have two options:

Skip the view completely

public function exportAction()
{
    $response = $this->getResponse();
    $response->setContent($csv);
    return $response;   // returning the Response object skips rendering
}

Render the view, but without the layout

public function partialAction()
{
    $view = new ViewModel(['items' => $items]);
    $view->setTerminal(true);   // no layout around it
    return $view;
}

Today: Zend Framework 2 lives on as Laminas MVC, where both techniques work the same way. For JSON, a JsonModel is usually cleaner.
