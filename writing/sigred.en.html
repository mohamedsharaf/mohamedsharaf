Tuesday’s Windows updates fixed CVE-2020-1350, called SIGRed: a bug in Windows DNS Server that has existed for 17 years. A malicious DNS response can let an attacker run code as SYSTEM. Microsoft rates it wormable and 10 out of 10.

In most companies, the domain controllers are also the DNS servers. That makes this as serious as it gets.

  1. Install the July update on every Windows Server running the DNS role, starting with domain controllers.
  2. If you can’t patch today, apply Microsoft’s registry workaround that limits the size of DNS packets over TCP, then restart the DNS service.
  3. Check that internal DNS servers aren’t reachable from the internet.

Windows clients aren’t affected, only servers running DNS Server. That makes the list short. Don’t let it wait.
