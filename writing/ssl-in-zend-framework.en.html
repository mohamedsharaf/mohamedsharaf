In 2012, HTTPS was expensive enough that many sites used it only where it mattered: login, cart and checkout. In Zend Framework 1 we did it with a front-controller plugin that read a list of secure pages from a config file:

; ssl.ini
ssl.modules.default.require_ssl = false
ssl.modules.default.controllers.account.require_ssl = true
ssl.modules.default.controllers.checkout.require_ssl = true

The plugin checked each request against that list in preDispatch() and redirected to the https:// address when needed (and back to http:// elsewhere).

Today: don’t do this. Certificates are free, HTTPS costs almost nothing, and mixing HTTP and HTTPS leaks session cookies. Serve the whole site over HTTPS, redirect all HTTP to it, and send an HSTS header so browsers never try plain HTTP again.
