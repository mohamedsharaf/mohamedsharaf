JetBrains IDEs such as PhpStorm normally keep their settings, caches and plugins in your user profile. To make the IDE portable, so it carries its settings with it, point those folders inside the IDE’s own folder.

  1. Download the .zip (or .tar.gz) version of the IDE, not the installer, and extract it to your drive.
  2. Open bin/idea.properties inside that folder in a text editor.
  3. Find the commented paths at the top and set them relative to the IDE’s folder:
idea.config.path=${idea.home.path}/user/config
idea.system.path=${idea.home.path}/user/system
idea.plugins.path=${idea.config.path}/plugins
idea.log.path=${idea.system.path}/log

On first start, the IDE creates the user folder next to itself, and everything (settings, plugins, caches) lives there. Copy the whole folder to a USB drive or a synced folder and take it anywhere.

Two tips: the system folder holds large caches, so a fast drive helps a lot; and you still need a valid licence or trial when you first run it.
