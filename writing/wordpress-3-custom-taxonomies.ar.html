لسنوات كان لدى ووردبريس طريقتان فقط لتجميع المقالات: الأقسام (بمستويات أب وابن) والوسوم (مسطّحة). جعل ووردبريس 3.0 التصنيفات المخصصة (Custom Taxonomies) ميزة أساسية، فتستطيع تعريف تجميعات خاصة تناسب محتواك: أنواع للكتب، مواقع للعقارات، مهارات لإعلانات الوظائف.

add_action( 'init', function () {
    register_taxonomy( 'genre', 'book', array(
        'label'        => 'Genres',
        'hierarchical' => true,   // like categories; false = like tags
        'show_in_rest' => true,   // available in the block editor and REST API
    ) );
} );

بعدها يحصل كل مصطلح على صفحة أرشيف خاصة به، يمكنك تنسيقها بقالب taxonomy-genre.php. والتصنيفات الجيدة قرار في هندسة المعلومات أكثر منها قرارًا برمجيًا: قرر كيف يبحث الزوار عن الأشياء، ثم جمّع المحتوى بتلك الطريقة.
