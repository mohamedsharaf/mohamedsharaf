أحيانًا لا يجب أن يعرض الـ Action أي قالب، مثلًا عندما يعيد ملفًا أو إعادة توجيه أو JSON خام. في Zend Framework 2 أمامك خياران:

تخطي العرض بالكامل

public function exportAction()
{
    $response = $this->getResponse();
    $response->setContent($csv);
    return $response;   // returning the Response object skips rendering
}

عرض الـ View لكن من دون الـ Layout

public function partialAction()
{
    $view = new ViewModel(['items' => $items]);
    $view->setTerminal(true);   // no layout around it
    return $view;
}

اليوم: يستمر Zend Framework 2 باسم Laminas MVC، والطريقتان تعملان بالأسلوب نفسه. وللـ JSON يكون JsonModel أنظف غالبًا.
