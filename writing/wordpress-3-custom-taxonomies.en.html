For years WordPress had only two ways to group posts: categories (with parent/child levels) and tags (flat). WordPress 3.0 made custom taxonomies a core feature, so you can define your own groupings that fit your content: genres for books, locations for properties, skills for job listings.

add_action( 'init', function () {
    register_taxonomy( 'genre', 'book', array(
        'label'        => 'Genres',
        'hierarchical' => true,   // like categories; false = like tags
        'show_in_rest' => true,   // available in the block editor and REST API
    ) );
} );

Each term then gets its own archive page, which you can style with a taxonomy-genre.php template. Good taxonomies are mostly an information-architecture decision, not a coding one: decide how visitors look for things, and group the content that way.
