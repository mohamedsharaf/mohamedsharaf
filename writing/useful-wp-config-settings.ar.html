معظم إعدادات ووردبريس موجودة في لوحة التحكم، لكن بعضها لا يوجد إلا في ملف wp-config.php. هذه التي أجد نفسي أستخدمها، وتضاف فوق السطر الذي يقول «That’s all, stop editing!»:

// Debugging: log errors to wp-content/debug.log, never show them to visitors
define( 'WP_DEBUG', true );
define( 'WP_DEBUG_LOG', true );
define( 'WP_DEBUG_DISPLAY', false );

// Keep at most 5 revisions per post
define( 'WP_POST_REVISIONS', 5 );

// Autosave every 2 minutes instead of every 60 seconds
define( 'AUTOSAVE_INTERVAL', 120 );

// Empty the trash after 7 days
define( 'EMPTY_TRASH_DAYS', 7 );

// Turn off the theme and plugin file editor in the dashboard
define( 'DISALLOW_FILE_EDIT', true );

// Give WordPress more memory
define( 'WP_MEMORY_LIMIT', '256M' );

// Always use HTTPS for the login page and the dashboard
define( 'FORCE_SSL_ADMIN', true );

اثنان منها مكسب أمني بسطر واحد: DISALLOW_FILE_EDIT يعني أن كلمة مرور مسروقة للمدير لا تكفي لتعديل ملفات PHP من المتصفح، وWP_DEBUG_DISPLAY بقيمة false يُبقي تفاصيل الأخطاء بعيدًا عن الزوار.
